MCP / AI Assistant

Start the MCP server in a terminal:

python -m hexcore mcp

Tools include analyze_binary, detect_format, list_sections, list_imports, list_exports, list_functions, get_function, disassemble_function, decompile_function, search_strings, search_bytes, get_xrefs, get_call_graph, get_cfg, investigate, compare_binaries, analyze_entropy, analyze_memory_layout, inspect_signature, get_security_findings, export_report, export_call_graph. The assistant must only use evidence from the workspace, with addresses and confidence levels — it must not fabricate disassembly or vulnerabilities.
